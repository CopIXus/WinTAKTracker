# Security policy

Please do not file public issues for vulnerabilities, credentials, exploit details, or private operational data.

Use GitHub private vulnerability reporting on this repository (Security > Advisories > Report a vulnerability). If private reporting is unavailable, contact the CopIX maintainers through an existing private channel and wait for acknowledgement before sharing details.

Public issue text, comments, screenshots, and logs are visible to anyone. Do not include passwords, tokens, private hostnames, or personal data. CopIX cannot reliably remove a secret after it has been published on a public issue.
